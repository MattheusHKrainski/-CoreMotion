# Fixtures de demonstração

Dados **fictícios** para demonstração (lojas, anúncios, comunidade, treinadores e notícias).

- Carregados somente com `NEXT_PUBLIC_DEMO_MODE=true` (desligado por padrão).
- Não há marcas reais, CNPJs, telefones ou e-mails reais aqui. Lojas de demonstração não aparecem como verificadas.
- Sem o modo demonstração, o app mostra as listas vazias e busca tudo no banco.

Para ver os dados de demonstração localmente, crie `.env.local` com `NEXT_PUBLIC_DEMO_MODE=true`.
